# Face Detector

A YuNet face detection server, packaged as a single Docker image that can be
reached four ways from the same underlying code (`src/lib/engine.py`):

- **CLI** — pass a file path, get thumbnail PNGs + a JSON manifest on disk.
- **HTTP** — upload a file, get the full result back in one response.
- **MCP tool over stdio** — pass a base64-encoded image, get faces back
  synchronously.
- **MCP tool over Streamable HTTP** — the same tool, reachable at `/mcp` on
  the HTTP server, for remote MCP clients that don't spawn a subprocess.

Detection is CPU-only and runs in single-digit milliseconds, so unlike
`upscaler`/`txt2img` there is **no job queue** — every call runs inline and
returns the full result directly (HTTP: `200`, not `202`+`job_id`).

Each detected face comes back with its bounding box and 5 landmarks (eyes,
nose tip, mouth corners) in original-image pixel coordinates, a confidence
score, and a ready-made cropped-and-resized thumbnail — the crop is padded
by a configurable `margin` fraction around the tight YuNet bbox before
resizing to `thumbnail_size` (default 256x256), so thumbnails don't clip
chin/forehead.

All examples below use `face-detector/tests/fixtures/faces.png` (a
synthetic, non-real-person portrait, generated specifically for this
pipeline's tests), matching exactly what `scripts/test_face_detector_cli.sh`,
`scripts/test_face_detector_http.sh`, and `scripts/test_face_detector_mcp.sh`
run — expected output is always 1 face, 256x256 thumbnail. That fixture's
face scores ~0.89, just under the default `score_threshold` of `0.9` (real
photographs typically score well above it), so the examples below pass
`score_threshold=0.5` explicitly to reproduce reliably.

## Build

```bash
./scripts/download_face_detector_models.sh
./scripts/build_face_detector_model_server.sh
```

## CLI

```bash
docker run --rm \
  -v "$(pwd)/face-detector/tests/fixtures:/data" \
  sinanozel/face-detector:yunet-cpu \
  detect --file /data/faces.png --output-dir /data/out --score-threshold 0.5
# -> /data/out/face_0.png, /data/out/detections.json
```

## HTTP (synchronous)

```bash
docker run -d -p 8080:8080 sinanozel/face-detector:yunet-cpu

curl -F "file=@face-detector/tests/fixtures/faces.png" -F "score_threshold=0.5" \
  http://localhost:8080/v1/detect
# -> {"width": 768, "height": 768, "faces": [{"bbox": [176, 170, 399, 532],
#      "score": 0.89, "landmarks": {...}, "thumbnail_base64": "..."}]}
```

Optional form fields: `thumbnail_size` (default 256), `margin` (default 0.3,
`0.0` = exact bbox with no padding), `score_threshold` (default 0.9),
`nms_threshold` (default 0.3). No queue, no polling — the response above is
the entire result.

Full OpenAPI docs (generated by `scripts/print_face_detector_openapi.sh`)
live under `face-detector/openapi/`.

## MCP (stdio)

The server is started with `docker run -i ... mcp` and speaks MCP over
stdio, exposing one tool:

```
detect_faces(image_base64: str, thumbnail_size: int = 256, margin: float = 0.3,
             score_threshold: float = 0.9, nms_threshold: float = 0.3) -> dict
```

Example call/response (see `face-detector/tests/mcp_client_test.py` for a
full working client):

```python
detect_faces(image_base64="<base64 of tests/fixtures/faces.png>", score_threshold=0.5)
# -> {"width": 768, "height": 768, "faces": [{"bbox": [176, 170, 399, 532],
#      "score": 0.89, "landmarks": {...}, "thumbnail_base64": "<base64 PNG, 256x256>"}]}
```

## MCP (Streamable HTTP)

The same tool is also reachable over HTTP on the HTTP server, at `/mcp`
(no separate container/mode needed — it's mounted onto the same FastAPI app):

```bash
docker run -d -p 8080:8080 model-servers/face-detector:yunet-cpu
```

Connect with any Streamable HTTP MCP client at `http://localhost:8080/mcp`
and call `detect_faces` the same way as over stdio. See
`face-detector/tests/mcp_http_client_test.py` for a full working client.

## Tests

Each interface is tested independently, against the real built image:

```bash
./scripts/test_face_detector_cli.sh
./scripts/test_face_detector_http.sh
./scripts/test_face_detector_mcp.sh
```

CPU-only — no `--gpus all` anywhere.
